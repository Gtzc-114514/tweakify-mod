## Tweakify Mod 1.1.2

本版本修复 1.1.1 的启动崩溃，并纳入 1.1.1 之后的 MC-8187 树苗修复。1.1.1 的 `@Expression` 注入缺少 MixinExtras 版本声明，游戏会在 `TreeFeature` 变换阶段直接退出；请升级到 1.1.2。

### 修复
- **启动崩溃**：客户端 Mixin 配置声明 `mixinextras.minVersion = 0.5.5`，`TreeFeatureSaplingGrowthMixin` 的 `@Expression` 可以正常应用
- **配置回归测试**：新增 `MixinConfigTest`，校验客户端 Mixin 配置的 MixinExtras 最低版本声明
- **MC-8187** `saplingGrowthFix`：2×2 云杉/丛林树苗在北/西侧有相邻方块时也能生长；默认关闭，仅在单人/局域网生效

### 验证
- 全量 **646** 个单元测试通过，6 个 GameTest 全部通过
- `gradlew build` 成功，`fabric.mod.json` 与产物版本均为 `1.1.2`
- 开发客户端启动冒烟到达 `Tweakify Mod initialized`，未再出现 `TreeFeature` 变换异常

### 兼容性
- 1.1.1 → 1.1.2 可直接覆盖升级，配置与存档无需迁移
- 没有新增配置项；MC-8187 的 `saplingGrowthFix` 默认关闭
- v1.1.1 的 jar 不可启动，发布页仍保留作历史记录，请勿继续使用

**完整变更**：https://github.com/Gtzc-114514/tweakify-mod/compare/v1.1.1...v1.1.2
