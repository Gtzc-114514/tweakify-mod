## Tweakify Mod 1.2.6

本版本新增日志清理、丢弃确认与启动时间三个实用功能，并把客户端退出保存改为异步后台排空：
关闭窗口不再等待磁盘 IO，慢盘/杀软扫描下也不会卡住退出界面。

### 新增功能

- **日志清理（通用标签）**：`logCleanup` / `logCleanupKeepCount` / `logCleanupOnStartup`
  在启动时把 `logs` 目录的日期编号归档清理到保留数量；`latest.log`、`debug.log`
  与未知文件永不删除。通用标签末尾新增只读操作项「立刻清理」，点击立即清理并以
  Toast 反馈，不写入配置。修改时间相同时按「日期 + 编号」数值排序，不会把 `-9`
  误判为比 `-10` 更新。
- **丢弃确认（功能标签）**：`dropConfirm` / `dropConfirmItems` 第一次按 Q / Ctrl+Q
  只取消本次丢弃，并在快捷栏上方提示“再按一次丢弃键确认丢弃 <物品>”；3 秒内对同一
  物品再按一次才真正丢弃。物品列表为空表示所有物品；只拦截
  `MultiPlayerGameMode.dropItem`，容器界面拖出物品的丢弃不受影响。
- **启动时间（通用标签）**：`startupTime` / `startupTimeLog` 首次加载完成时按 JVM
  uptime 显示一次“启动游戏”耗时（快捷栏上方 Toast），可选写入模组日志；使用专用
  通知 id 并延迟到主菜单首帧，避免被资源包加载失败等系统通知挤掉或推迟显示。

### 优化

- 退出保存改为异步：配置、收藏、进度状态与滚动记忆只提交最终快照，
  `CLIENT_STOPPING` 立即返回；非 daemon 收尾线程在后台排空写盘队列，30 秒超时后
  先执行同步兜底再放弃，收尾线程启动失败时退回调用线程限时等待。
- 退出时停留在配置界面时，`Screen.removed()` 之后产生的最后一批配置修改与滚动位置
  改为同步兜底写，避免静默丢失。

### 兼容性

- 新增 7 个配置项，未删除或重命名任何现有配置；旧配置读取后按默认值补全，
  存档格式无变化。
- 四种语言（zh_cn / en_us / ru_ru / fr_fr）键集保持一致；`docs/features.md`
  与相关技术债文档已同步。
