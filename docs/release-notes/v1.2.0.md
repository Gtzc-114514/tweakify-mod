## Tweakify Mod 1.2.0

本版本为功能版本：新增「显示」标签与范围可视化，加入更好的 F2 截图和 F9 真正 4K 截图，补充告示牌文本优化，并完善收藏与配置体验。

### 显示与范围可视化

- **新增「显示」标签**：攻击范围、爆炸范围、横扫范围、屏障可见、单层基岩、方块轮廓与实体高亮集中到同一分类
- **攻击范围**：支持平面/球体显示、线框/实心渲染、颜色、最大距离与目标数量；实心渲染额外叠加线条，兼容 Vulkan/Vitrail
- **爆炸范围**：标记 TNT、TNT 矿车、苦力怕与末地水晶的爆炸半径
- **横扫范围**：参考 `sweeping-view`，手持剑时显示球体范围；瞄准生物、船或矿车时显示目标扩展框，支持线框、面框、实心面框与载具目标子项

### 截图

- **更好的 F2 截图**：截图后在聊天框显示缩略图、时间、文件名与坐标；文件名包含坐标，可点击打开截图文件夹，右侧可删除
- **截图格式**：F2 与 F9 支持 PNG / JPG / TGA / BMP
- **F9 真正 4K**：临时把窗口与主渲染目标切到 3840×2160，按真实渲染帧等待后抓取；1K 屏幕也能输出真实 4K 细节，完成后恢复原窗口、全屏状态与窗口化几何
- **F9 稳定性**：修正高 DPI 窗口尺寸换算、异常恢复、超时/取消后的迟到回调，并为恢复状态机增加单元测试
- **F2 行为**：F9 4K 截图处理中按 F2 会提示等待，不会抓到过渡态画面；恢复后 F2 使用原生分辨率

### 优化

- **告示牌文本优化**：缓存原始与过滤文本状态，跳过客户端告示牌空 tick；开启后告示牌渲染使用未过滤文本，默认关闭

### 配置与界面

- **收藏系统父项**：通用标签新增收藏总开关，收藏星样式与「包含子项」作为子设置；配置项与存档列表共用收藏状态
- **附魔台附魔信息**：悬停附魔选项时显示实际会获得的附魔名称与等级
- **盔甲架手臂与隐藏展示框**：加入修改标签，可按需开启
- **取消速度上限**：加入修改标签，关闭服务端移动速度检查
- **README 功能一览**：所有功能表统一为「功能 / 说明 / 类型 / 默认值」四列，便于检索配置项

### 测试与兼容性

- 新增 F9 4K 恢复状态机测试，覆盖超时、取消、迟到回调与恢复幂等
- 单元测试、Fabric Loader 集成测试与 GameTest 通过，完整构建通过
- 1.1.9.1 → 1.2.0 无存档数据变更；新增配置项均有默认值，已有配置会自动补齐
- 所有新增渲染与截图功能均为客户端行为，服务端无需安装本模组
