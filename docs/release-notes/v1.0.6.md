## Tweakify Mod 1.0.6

本轮为**依赖升级与技术债口径收尾**：Fabric Loader 最低要求提升到 0.20.1，世界叠加层扫描的技术债验证口径完成多轮复核收敛；没有新增或改变任何配置语义，配置文件可直接沿用。

### 依赖与兼容性
- Fabric Loader：0.19.5 → 0.20.1，同步 `gradle.properties`、`fabric.mod.json` 的 `depends` 与 README 环境要求表
- Minecraft 26.3、Fabric API 0.163.0+26.3、MaLiLib 0.30.2、Mod Menu 21.0.0、MiniHUD 0.41.2 版本要求不变
- 未改动任何 Java 源码与 Mixin 注入点，探针覆盖仍为 51/51；`config/tweakify-mod.json` 沿用 1.0.5

### 技术债与文档
- `docs/tech-debt.md`：T1 判定口径以 v1.0.4（`2e4d87c`）为基线，明确 A/B/C 场景、3 轮中位与冷启动/热缓存构成；T3 判定口径与检查表对齐；状态列新增“最近复评”格式
- `docs/t3-profiler-checklist.md`：`avgLayerUs` 换算改为窗口法（修正除数与 µs 单位），补 D/E 不适用限定、中位行与必填列说明；与台账、release-pipeline、mixin-probes 的描述同步
- 本次无 `release.yml` 改动，版本一致性校验链与 notes 机制沿用 v1.0.5

### 测试
- 全量单测通过（含 `BlockMarkerScannerTest`、`RefreshSchedulerTest`、`CachedGeometryTest`、两个 GeometryCache 测试、`AttackRangeStateTest`、`BedrockHighlightStateTest`）
