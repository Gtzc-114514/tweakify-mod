## Tweakify Mod 1.2.7

本版本新增消耗品优化、雕刻书架可视化、禁用玩家盔甲渲染、快速滚动、NBT 自动补全与更好的盔甲架
六个功能，并补齐配置版本 5 迁移、旁观者交互与跨维度快照等复查修复。

### 新增功能

- **消耗品优化（优化标签）**：`consumableOptimization` 与三个子项。客户端本地完成进食与饮用，
  高延迟下不再卡在进食动画里；本地立即播放音效、粒子与打嗝，并吃掉服务端随后回放的完成事件与
  重复音效。抑制窗口按当前延迟自适应（3×RTT，500ms–2s），音效归属半径 2–6 格随 RTT 放宽，
  高延迟下不会过早放弃，也不会误吞远处其他玩家的进食声。只对远程服务器生效，单人/局域网保持原版。
- **雕刻书架可视化（显示标签）**：`chiseledBookshelfVisualizer` 与四个子项。准星指向雕刻书架时
  在准星下方显示 6 格书本，悬停格子显示名称与附魔；单人/局域网通过集成服务端读取内容，
  远程服务器回退到客户端方块实体。
- **禁用玩家盔甲渲染（修改标签）**：`disablePlayerArmorRendering` 与「仅其他玩家」子项。
- **快速滚动（通用标签）**：`fastScroll` / `fastScrollMultiplier`。按住 Shift 滚动时把界面滚轮
  增量放大 2–10 倍；快捷栏切换与不经过界面的滚轮分支保持原版。
- **NBT 自动补全（功能标签）**：`nbtAutocomplete`。命令输入框内补全数据组件 ID 与常用 NBT 键名；
  前缀匹配不区分大小写，插入时使用规范大小写，只接管原版没有候选的位置。
- **更好的盔甲架（功能标签）**：`betterArmorStands` 父开关，包含盔甲架姿态（潜行空手右键循环预设）、
  红石驱动（上升沿循环、首个 tick 只播种电平）、姿态预设列表与盔甲架手臂（从修改标签迁入，
  含「仅持物时显示」「仅小型盔甲架」两个子项）。

### 优化与修复

- 配置版本 4→5 迁移：旧 `armorStandArms` 自动并入「更好的盔甲架」父开关；配置档案与主配置共用
  迁移逻辑，`configVersion` 为 JSON null 时统一按缺省处理。
- `armorStandPosePresets` 登记为自由格式列表，避免被物品 ID 清洗改写成命名空间形式；解析时可省略
  `minecraft:` 前缀、未知代码忽略、重复姿态去重。
- 旁观者与原版一致不能再通过潜行右键修改盔甲架姿态；雕刻书架快照与刷新节流键加入维度，
  跨维度同坐标不会显示上个维度的内容。
- 红石上升沿状态机独立为 `ArmorStandRedstoneTrigger`，区块重载后线路保持通电不会误切。
- 快速滚动与 NBT 补全的注入改为 `require = 0` + `HookProbe`（`fastScroll` / `nbtAutocomplete`），
  与滚动/命令补全类模组冲突时降级而不是启动失败。

### 兼容性

- 新增 20 余个配置项与 1 个配置版本迁移；未删除或重命名现有配置项（`armorStandArms` 迁移为
  「更好的盔甲架」的子项）。
- 四种语言（zh_cn / en_us / ru_ru / fr_fr）键集保持一致；`docs/features.md`、README、
  `docs/mixin-probes.md` 与相关技术债文档已同步。
