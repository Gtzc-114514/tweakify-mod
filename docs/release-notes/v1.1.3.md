## Tweakify Mod 1.1.3

本版本把界面滚动全面改为像素级平滑：配置界面、创造模式物品栏、聊天栏与 Mod Menu 列表共用一套缓动滚动，并新增配置搜索关键词高亮。创造栏的平滑滚动与物品分组完全兼容，滚轮、右侧滑块、切页、分组展开与窗口缩放之间不再跳位。

### 新增

- **平滑滚动（四处界面）**：滚轮与拖动位移先累加为目标位置，每帧按真实时间指数缓动，帧率变化不影响手感
  - 配置界面：支持亚行像素滚动，并可按住左键从名称/空白处拖动列表（3 像素起拖阈值，不抢按钮与滑块事件）
  - 创造物品栏：自绘 9×5 槽位底纹与一行预告内容，物品格随偏移整体上移，真正逐像素滚动
  - 聊天栏：整行仍交给原版推进，不足一行的部分按聊天缩放与行距换算后平移补足
  - Mod Menu：列表每帧写回滚动值（条目原生支持 1 像素步进）
- **与物品分组兼容**：展开/收起保留亚行位置恢复顶部行；组图标与成员格判定改用精确显示索引，滚动时图标格不再闪烁；组成员格在预告行中同步变灰
- **滑块与状态同步**：拖动创造栏右侧滑块时按实际填充行校正，底部预告行不再与第 5 行重复；切页、搜索刷新、窗口缩放、配置热更新都会对齐到新的滚动位置
- **配置界面搜索高亮**：命中关键词在名称与配置键上以金色分段显示，多个关键词用 `|` 分隔；超宽截断时优先保留命中片段
- **子设置**：新增 `smoothScroll` 总开关、按界面开关（配置列表 / 创造栏 / 聊天栏 / Mod Menu）与平滑时长（30 ~ 400 毫秒），默认全部开启

### 修复

- 数字/文本输入框在配置列表滚动时跟随整行移动，框内数字与光标位置不再滞留
- 创造栏首行悬停高亮在滚动到半行时不再被裁到只剩几像素（首行固定放开 4 像素外扩，不压到标题栏）
- 配置列表滚动时的悬停判定与裁剪区取交集，被裁掉的行不会抢走搜索框的悬停

### 验证

- 全量 **683** 个单元测试通过（1.1.2 为 646），6 个 GameTest 全部通过
- 新增单测覆盖：缓动收敛与吸附阈值、行/亚行换算、网格命中矩形与显示索引、分组恢复位置、高亮区间与截断窗口、底板贴图约束、注入目标反射校验
- `gradlew build` 成功，`fabric.mod.json` 与产物版本均为 `1.1.3`

### 兼容性

- 1.1.2 → 1.1.3 可直接覆盖升级，配置与存档无需迁移
- 新增配置项默认开启；旧配置文件缺少这些字段时按默认值处理，不需要手动补全
- 未安装 Mod Menu 时，其列表的平滑滚动自动不生效，其余界面不受影响
