## Tweakify Mod 1.2.5.1

紧急修复：与部分模组（如 Entity Texture Features）同时安装时的启动崩溃。

### 崩溃修复

- **启动初始化循环**：`TweakifyMod` 类初始化时创建带默认物品列表的配置，会扫描 `BuiltInRegistries` 并解析物品 ID；若第三方模组（如 ETF）在 `Identifier` 校验中回调语言系统，语言 mixin 会再次进入 Tweakify 的配置初始化，形成循环并崩溃。
- 修复：类初始化阶段改用轻量占位实例 `createPlaceholderInstance()`，只做字段初始化与缓存重建，不填充依赖注册表的列表；真实默认值仍由 `load()` 在模组初始化完成后提供。
- 新增回归测试，确保占位实例的默认列表保持为空。

### 兼容性

- 无配置/存档格式变更；1.2.5 → 1.2.5.1 行为与默认值不变（默认列表在 `load()` 后照常填充）。
- 单元测试 **886 项**、Fabric Loader Mixin 集成测试 **2 项**、服务端 GameTest **6 项**全部通过。
