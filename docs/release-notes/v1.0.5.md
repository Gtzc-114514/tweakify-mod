## Tweakify Mod 1.0.5

本轮为**世界叠加层顶点缓存的失效粒度优化**：扫描结果或实体条目内容未变时不再重复重建顶点数组，并补上前一版审查发现的精确比对与排序稳定性修正；没有新增或改变任何配置语义，配置文件可直接沿用。

### 性能
- 顶点缓存去重：`BedrockHighlightState` / `AttackRangeState` 发布前计算内容摘要，摘要相同且精确比对一致时保留旧列表引用，基岩每秒 6 次、攻击范围每秒 12 次的整表重建在内容未变时全部跳过
- 精确比对兜底：摘要只作预筛，命中后再逐条比对（基岩 `equals`，攻击范围只比几何字段），哈希碰撞不会让几何停在旧内容
- 攻击范围排序：`BY_DISTANCE` 补坐标/半径并列规则，等距实体顺序确定，不会因迭代顺序变化而误重建或让最近目标在轮次间抖动
- 状态管理：摘要与“是否已发布”合并为可空 `Integer`，关闭功能与重置统一走 `resetState()`，避免两个状态位失同步；摘要比较改用 `Objects.equals`，null 安全且不会退化为引用比较

### 测试
- `AttackRangeStateTest`：新增空内容/摘要为 0 的去重用例、输入顺序交换、等距并列、`maxTargets` 截断的复用与重发
- `BedrockHighlightStateTest`：新增超上限截断的复用与重发，保留单层与位面判定覆盖
- 全量单测通过；可空 Integer 的 null/0 区分、精确比对与并列排序均有对应断言

### 兼容性
- 对外功能与配置语义不变，`config/tweakify-mod.json` 沿用 1.0.4
- 本次未改动 Mixin 注入点，探针覆盖仍为 51/51
- 屏障/基岩/攻击范围的扫描半径与刷新频率保持 1.0.4 的行为，仅减少内容未变时的无效重建

### 构建与发布
