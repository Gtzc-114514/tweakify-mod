## Tweakify Mod 1.1.0

本轮为「功能 / 修改 / 修复 / 优化 / 通用 / 测试」六个标签集中补齐 51 个可调子设置：把原先只有单一开关的功能扩展到数值、枚举与附加布尔门控，所有默认值均保持旧行为；同时完成全局单开关与“假开关”审计，确认新增选项均已接入真实行为。

### 功能标签：渲染与 HUD
- 如履平地：跨步高度 `one_block` / `one_and_half` / `two_blocks`
- 实体高亮：描边样式 `outline` / `blink`、闪烁周期 10 ~ 200 tick、描边颜色（原版队伍色与 7 种固定色）
- 单层基岩高亮：扫描半径 8 ~ 32 格、标记颜色 5 种；颜色变化自动重建顶点缓存
- 屏障可见：扫描半径 8 ~ 32 格、同一方块标记间隔 20 ~ 200 tick
- 药水时间显示：低时长过滤阈值 0 ~ 600 秒、时间文字配色 `auto` / `white` / `yellow` / `red`
- 生物攻击范围：新增范围颜色，支持 7 种调色板

### 功能标签：交互与输入
- 中键液体桶：液体范围 `water_and_lava` / `water_only` / `lava_only`
- 生存模式中键取物：可关闭液体处理，只取方块与实体
- 便捷焚烧：可要求按住潜行键再焚烧
- 刷怪蛋投掷：投掷速度 50% ~ 200%、潜行时保持原版放置
- 更好的放置：潜行时保持原版放置
- 聊天文本选择：选区不透明度 10% ~ 100%
- 聊天输入记忆：可忽略以 `/` 开头的命令

### 修改标签：移动、视角与屏幕
- 使用物品减速：保留原版减速的百分比 0 ~ 100
- 疾跑视野：保留原版强度的百分比 0 ~ 100%
- 切换工具挖掘：保留进度的最大距离 0 ~ 16 格
- 经过可攀爬方块：可限定仅潜行时跳过水平夹紧
- 受伤抖动：关闭抖动时保留死亡镜头倾斜
- 受伤变红：关闭变红时保留受伤闪白
- 第三人称自身名字：可限定仅潜行时显示
- 连接方块轮廓：门使用两格视觉高度
- 资源包兼容性提示：可同时忽略数据包

### 修改标签：提示文本与附魔
- 附魔等级阿拉伯数字：`plain`（锋利 3）/ `parentheses`（锋利 (3)）
- 附魔描述：可限定仅潜行时显示
- 水下与空中挖掘惩罚：各保留 0 ~ 100 百分比
- 诅咒移除：`all` / `binding_only` / `vanishing_only`
- 移除附魔冲突：可限定仅同一互斥组
- 附魔过于昂贵：费用上限 0 ~ 1000 级、超出后可仅提示不阻止
- 可见交易：可只显示尚未解锁的锁定交易
- 保留火把：剩余数量阈值 1 ~ 8
- 锻造模板：保留概率 0 ~ 100
- 床太远：最大入睡距离 0 ~ 128 格
- 铁傀儡进矿车：玩家附近距离 0 ~ 64 格
- 穿牌打开容器：潜行时保持原版
- 雪傀儡群系免疫：可限定仅主世界
- 疣块分解：产出数量 1 ~ 9

### 修复 / 优化 / 通用 / 测试
- 草径卡船修复：可限定仅载有玩家的船
- 鹦鹉肩膀跳舞：可限定仅本地玩家
- 更好的粗体：偏移百分比 10 ~ 100（默认 50 = 0.5 像素）
- 冰霜行者跳跃修复：可限定仅跳跃上升段
- MiniHUD 掉帧优化：刷新间隔 50 ~ 1000 毫秒
- 标签记忆：新增未记忆时的默认标签（7 个分类）
- 已启用功能报表：支持输出到剪贴板

### 兼容性与质量
- 51 个子设置默认值全部保持改动前行为，旧配置文件无需迁移
- 新增 10 个配置枚举；四语言各 1221 个键且键集严格一致
- 新增状态判定与纯函数均有单元测试覆盖；全量 580 个用例通过
- `gradlew build` 成功；README 功能表与默认值已同步
