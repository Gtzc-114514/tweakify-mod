## Tweakify Mod 1.0.9

本轮为功能与测试标签补充可调子设置与调试工具，并完成物品分组的一轮系统性修复：滚动错位、自定义组跨页生效、收起组轮播、配置热更新清空预览等问题已修复，同时补齐告警与边界测试。

### 功能标签新增子设置
- 生物攻击范围：新增“只显示敌对生物”与“显示隐身实体”
- 装备耐久显示：新增文字配色 `auto` / `white` / `yellow` / `red`
- 复制物体 ID：新增“保留命名空间”，关闭后只复制路径部分
- 药水效果时间显示：新增“固定按秒显示”，长文本按图标宽度缩小
- 屏障可见：新增标记上限 16 ~ 256，默认 256 与旧版一致

### 测试标签调试能力
- 调试叠加层新增生物群系、移动速度、附近实体、配置统计、药水效果五行；实体与配置统计按 500ms 节流
- 钩子探针报表支持输出到剪贴板
- 新增“已启用功能报表”快捷键，输出已启用的根功能开关

### 物品分组修复
- 滚动后显示索引偏移随槽位内容重算，图标/成员标记与点击判定不再错位
- 自定义组只在行首标签页生效；tabId 大小写不敏感、缺命名空间按 `minecraft:` 补全（`:combat` 等价 `minecraft:combat`）
- 收起的组不再轮播图标；切换轮播开关不再重建列表、保留已展开的组
- 配置热更新只重建分类页；搜索/快捷栏/背包页不再清空预览，非分类页只告警
- 自定义组告警覆盖未注册与非分类页，同一标签页每屏只提示一次；格式错误行（字段不足/空 tabId/空包含项）提示一次并忽略，整行空白忽略

### 测试、语言与文档
- 物品分组 37 个用例，覆盖滚动锚点、展开态、标签门禁、告警去重/端到端/格式错误行
- README 与四语言同步新增配置项、分组说明与调试功能
- 新增 T4 技术债条目：mixin 配置热更新转发无自动化覆盖
