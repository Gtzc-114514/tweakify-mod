## Tweakify Mod 1.1.9

本版本为工程化维护版本：没有新增功能或配置字段，重点是测试覆盖、构建门禁与配置代码结构；对 1.1.8 的配置与存档完全兼容。

### 用户可见

- **界面预览**：README 新增配置界面与存档列表截图
- **Mod Menu**：模组简介改为中英双语，模组页面新增 GitHub Releases 与 Issue Tracker 入口

### 测试与质量门禁

- **Mixin 清单校验**：新增单测锁定 145 个 mixin 与源码的双向一致性，防止漏登记导致功能静默失效
- **全量织入验证**：loaderTest 在真实 Fabric Loader 环境加载全部 145 个 Mixin 的 100 个去重目标类；`require = 0` 的 73 个探针点按设计豁免
- **主源集 -Werror**：main/client 编译警告视为错误，CI 阻断新警告
- **覆盖率报告**：JaCoCo 只出报告、不设阈值；统计排除 mixin 包，核心逻辑行覆盖率 61.4%
- **语言文件测试收敛**：按功能罗列的硬编码清单改为全量派生断言，枚举翻译键一次覆盖 31 个实现

### 构建与发布

- Gradle 构建堆提升到 3G；Dependabot 托管 GitHub Actions 与 Gradle 依赖更新

### 内部重构

- `TweakifyModConfigOptions`（1555 → 715 行）与 `ConfigCatalog`（559 → 218 行）按 6 个标签页拆分；`ALL_OPTIONS` 与 `optionNames()` 顺序经基线比对完全一致

### 性能采样

- T3/T5/T6 首轮实机 JFR 采样：T3 在屏障 + 基岩场景占 Render thread 6.11%（单轮，待 3 轮复测）；T5 调试层整层渲染 4.21%；T6 渲染线程无几何构建。数据与缺口记入 `docs/tech-debt.md` 与 `docs/t3-profiler-checklist.md`
