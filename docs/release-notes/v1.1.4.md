## Tweakify Mod 1.1.4

本版本新增配置与存档收藏系统：配置项可一键收藏并在独立「收藏」标签集中查看，存档列表支持收藏、置顶与删除保护；同时统一优化了全部配置项的中文显示名，并同步英文、俄文、法文与 README。

### 新增

- **配置收藏**：每条配置行右侧（重置/打开按钮右边）新增收藏星；新增「收藏」标签（位于「测试」右侧），只显示已收藏项，取消收藏后该行立即消失
- **存档收藏**：存档列表每行左侧新增收藏星，收藏存档自动置顶；记录列表原始顺序，取消收藏后回到原位置
- **删除保护**：收藏的存档删除按钮置灰并提示，`deleteWorld` / `doDeleteWorld` 双重拦截，避免从确认框或调试重建入口误删
- **收藏星样式**：新增 `favoriteStarStyle`（`star` 自绘星形 / `nether_star` 原版下界之星），同时作用于配置行与存档行
- **独立收藏文件**：收藏数据写入 `config/tweakify-mod-favorites.json`，复用原子写盘、提交序号与坏文件备份；退出时限时同步兜底，不影响主配置与档案
- **名称优化**：53 项配置中文显示名统一术语、空格与长度，README 功能一览同步；en_us / ru_ru / fr_fr 对应名称按新语义对齐

### 改进

- 收藏置顶使用原版列表排序，不重建条目，避免销毁存档图标纹理
- 排序保留选中态；取消收藏按列表原始顺序回位，并实时刷新删除按钮状态
- 收藏列表每次填充时自动清理已被外部删除/改名存档的悬空收藏

### 验证

- 全量 **706** 个单元测试通过（1.1.3 为 683），6 个 GameTest 全部通过
- 新增单测覆盖：收藏存储与坏文件回退、排序/回位/收敛、收藏标签可见集合、星标几何与纹理尺寸、四语言键集
- `gradlew build` 成功，`fabric.mod.json` 与产物版本均为 `1.1.4`

### 兼容性

- 1.1.3 → 1.1.4 可直接覆盖升级，配置与存档无需迁移
- 仅优化显示名，配置字段名与配置文件键不变；现有配置无需修改
- 新增配置项 `favoriteStarStyle` 默认 `star`，旧配置缺少该字段时按默认值处理
- 收藏数据独立存放，首次收藏时自动创建；仅单人存档列表显示存档星标，Realms 上传列表不受影响
