## Tweakify Mod 1.1.7

本版本为测试基础设施维护版本：T4 的配置变更转发保护升级为 Fabric Loader JUnit 真实加载客户端 Mixin 的集成测试，不包含运行时行为变更。

### 变更

- **T4 真实 Mixin 集成测试**：新增独立 `loaderTest` 源集与任务，在 Fabric Loader JUnit 的 CLIENT 环境加载 `CreativeModeInventoryScreen`，验证 `CreativeModeInventoryGroupingMixin` 的 `@Unique` 字段与 `containerTick` 目标方法已织入
- **隔离加载环境**：`fabric-loader-junit` 仅进入 `loaderTest`，普通 708 个单测保持原注册表/tags 环境，避免 `Unbound tags`
- **双层保护**：保留源码接线契约测试（`@Inject` 方法名、转发接缝、刷新调用）与接缝单测
- **CI 自动执行**：`check` 依赖 `loaderTest`，`./gradlew build` 自动运行
- `.gitignore` 忽略 Loader 生成的 `.fabric/` 缓存

### 验证

- 708 个普通单元测试通过
- 1 个 Fabric Loader 集成测试通过（CLIENT 环境 + Mixin 织入）
- `gradlew build` 与 6 个 GameTest 通过
- 版本 `1.1.7` 的 `fabric.mod.json` 与产物一致

### 兼容性

- 1.1.6 → 1.1.7 无运行时行为、配置字段、存档或收藏数据变化
- 仅测试基础设施与文档，不影响游戏内功能
