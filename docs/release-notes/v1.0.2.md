## Tweakify Mod 1.0.2

本轮为诊断与工程改进，**没有新增或改变任何对外功能与配置语义**：jar 的功能行为与 1.0.1 完全一致，
配置文件可直接沿用，替换即用。

### 诊断
- 最后 8 个 `require = 0` 注入点补齐 `HookProbe` 探针，全仓 **51 个注入点 1:1 覆盖**
- 34 个探针字段统一为 `TWEAKIFY$XXX_PROBE` 命名，日志名保持不变
- 功能失效时的排查方式：日志里**没有** `Mixin hook active: <名称>` 条目 = 注入失败（通常被其他模组改写了目标方法）；
  有条目但功能不生效 = 注入正常、问题在逻辑或配置

### 文档
- 新增 `docs/release-pipeline.md`：发布流水线的步骤顺序、失败语义与已知取舍
- 新增 `docs/mixin-probes.md`：探针约定、51/51 覆盖率与可复现的校验脚本

### 构建与发布（对使用者无影响）
- 发布流水线新增：标签名与 `gradle.properties` 的版本一致性校验、发布正文优先使用版本化 notes 文件、
  校验工具链预检与分层失败归因
