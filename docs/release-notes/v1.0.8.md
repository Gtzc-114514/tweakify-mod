## Tweakify Mod 1.0.8

本轮把定位栏与参考实现 `Haage001/locator-heads` 的剩余差异补齐：玩家过滤改为包含/排除双名单、描边粗细改为四档、指南针接入 Flashback 回放检测；配置版本升到 4，旧配置会自动迁移（无需手动改文件）。

### 定位栏（功能标签）
- 过滤：`locatorBarHeadFilterNames` 拆分为 `locatorBarHeadIncludedPlayers` 与 `locatorBarHeadExcludedPlayers` 两个名单，与参考实现一致——`include` 只看包含名单、`exclude` 只看排除名单、`all` 不解析名单；命中时整条航点（含圆点）隐藏
- 描边粗细：由 1～3 像素改为参考实现的四档 `thin` 0.3 / `medium` 0.5 / `normal` 1.0 / `thick` 2.0，渲染继续使用 0.01 缩放下的 `thickness * 100`
- 指南针：新增 Flashback 回放检测（反射 `Flashback.isInReplay`，未安装时视为否），回放时不绘制

### 配置迁移（自动）
- 配置文件版本 3 → 4
- 旧 `locatorBarHeadFilterNames` 列表按当时的过滤模式并入对应名单（`exclude` → 排除名单，其余 → 包含名单），旧键在下次写盘时移除
- 旧描边粗细整数按 1 → `normal`、2/3 → `thick` 迁移，未知值回退 `normal`

### 语言与文档
- 四语言各新增 2 个名单键（name/prettyName/comment）与 4 个档位取值键，键集保持 987 一致
- 顺带修正此前四个语言里被截断/串语言的描边粗细注释
- README 的过滤与描边行按新配置更新，指南针补充 Flashback 说明

### 内部质量
- Mixin 探针覆盖 58/58（`AtomicBoolean` 39 个、含探针文件 34 个逐文件 1:1），本次未新增注入点
- 新增测试：v3→v4 迁移（旧名单 + 旧整数）、四档像素表、Flashback 安全返回；过滤语义与语言键校验同步更新
- `gradlew build` 全量测试通过
