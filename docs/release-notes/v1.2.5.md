## Tweakify Mod 1.2.5

本版本为质量与工程化版本：不新增功能、不改变配置与存档格式，集中补齐测试、拆分结构、完善 CI 与文档。

### 质量与测试

- 单元测试增至 **885 项**（新增 26 项）：聊天框选、物品分组/夜视曲线、主动爬行、加载界面、定位栏指南针、锁定交易网络包 codec、README 功能表与配置目录一致性等。
- 缓存失效补测：附魔 tooltip 的包含诅咒维度、连接方块轮廓的开关切换、定位栏名字淡入状态隔离。
- `TweakifyModConfigTest` 按 7 个主题（加载/迁移/序列化/回滚/字段表/列表/数值）用 `@Nested` 重组，断言不变。
- 和平逻辑接线收敛为 `SpawnFeatureState` 两个重载，10 处 mixin 统一；补齐 3 个 `require = 0` 探针并新增探针配平测试。

### 构建与 CI

- Gradle wrapper 升级到 **9.9.2**，构建堆上限 3G → 4G；新增 `.editorconfig`（tab + UTF-8 + LF）。
- CI 新增 **Windows 编译 job**（windows-latest，三个源集编译），与 Linux 完整构建并行。
- 新增 `-PskipGameTest` 快捷跳过本地 GameTest；CI 仍默认执行。

### 结构整理

- `TweakifyMod.CONFIG` 私有化并提供 `config()` 入口；默认配置实例消除约 270 处判空。
- client 包按职责拆分为 `config`/`render`/`state`/`ui`；T9（测试专用 public）与 T10（config → ui 依赖）闭环。
- 配置版本迁移与旧键清洗抽取到 `ConfigMigration`。
- 24 个纯规则类由 `*State` 改名为 `*Rules`（有状态类保留 `State`）。
- README「功能一览」迁移到 [`docs/features.md`](../features.md)，台账已闭环条目归档到 `docs/tech-debt-archive.md`。

### 兼容性

- 无新增/删除配置项，1.2.4 → 1.2.5 无存档数据变更；旧配置读取行为不变。
- 单元测试 **885 项**、Fabric Loader Mixin 集成测试 **2 项**、服务端 GameTest **6 项**全部通过；GitHub Actions 的 Linux build 与 Windows compile 均通过。
- 模组仍为客户端环境；涉及服务端判定的功能仅在单人/局域网主机生效。
