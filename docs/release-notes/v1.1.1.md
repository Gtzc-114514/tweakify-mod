## Tweakify Mod 1.1.1

本次为修复与性能收尾版本：新增 12 项默认关闭的原版 bug 修复开关，完成 HUD/GUI 每帧重复计算的 T5 缓存化，并补齐世界扫描边界与 GameTest 覆盖。旧配置文件无需迁移。

### 修复标签
- **MC-577** `fixMouseButtonInventory`：物品栏中绑定到鼠标键的关闭背包/丢弃物品按键生效
- **MC-247973** `chatLagFix`：聊天消息触发的屏蔽名单拉取改为后台执行，避免主线程网络阻塞
- **MC-79545** `experienceBarHighLevelFix`：等级极高时经验需求溢出不再让经验条整条消失
- **MC-61489** `bookGuiVerticalCenterFix`：书本查看与书与笔编辑界面垂直居中，底部按钮不再贴边
- **MC-84661 / MC-170462** `potionTooltipCategoryFix`：药水提示中的「发光」与「不祥之兆」按有害效果显示
- **MC-105068** `shieldBlockHurtSoundFix`：完全格挡攻击时不再叠播玩家受伤音效
- **MC-217716** `spectatorOverlayFix`：旁观者模式下隐藏反胃与下界传送门覆盖层
- **MC-268420** `cooldownIndicatorFix`：高攻速切换物品时攻击冷却指示器不再闪一帧
- **MC-4490** `fishingLineThirdPersonFix`：潜行时第三人称鱼线仍连接到鱼竿
- **MC-143474** `respawnHotbarFix`：重生后保留死亡前的快捷栏选中槽位
- **MC-159163** `sneakAnimationFix`：快速按潜行键时不再重复播放潜行动画
- **MC-121706** `skeletonAimingFix`：骷髅与幻术师射箭时视线随目标上下

### 性能与稳定性
- 定位栏名单解析与玩家名宽度、药水计时、附魔 tooltip、调试信息叠加层、连接方块轮廓改为按 tick/签名缓存，减少每帧重复计算
- 修复调试摘要节流 `Long.MIN_VALUE` 溢出导致的永不刷新
- 附魔 tooltip 缓存断开连接时清理，避免跨世界持有旧注册表数据
- 世界底部与越界负 y section 的扫描诊断改为按需开启，并补齐 GameTest 边界覆盖

### 构建与测试
- 全量 **642** 个单元测试通过，6 个 GameTest 全部通过
- `gradlew build` 成功，版本号、`fabric.mod.json` 与产物均为 `1.1.1`
- `action-gh-release` 升级到 v3（Node.js 24）
- 项目许可证统一为 MIT

### 兼容性
- 12 个修复开关默认关闭，旧配置无需迁移
- `shieldBlockHurtSoundFix` 与 `skeletonAimingFix` 依赖集成服务端，仅在单人/局域网生效
- 其余修复为客户端输入、渲染或数据包处理，不要求服务端安装模组
