## Tweakify Mod 1.0.7

本轮为**功能扩展**：定位栏支持玩家头像、描边、名字、过滤与指南针，并可让经验条与定位栏同时显示；物品分组按 `BizCub/inventory-item-groups` 完全重做；新增四类移动物理开关（含禁用粘液块弹跳、禁用蜂蜜块黏着、水流/岩浆分开关、蛛网全实体生效等子设置）、冰霜行者跳跃修复、穿牌打开容器与铁傀儡只坐普通矿车，测试标签补齐调试叠加层与探针报表。配置文件新增 34 个选项，旧配置可原样沿用（新选项使用默认值）。

### 定位栏优化（功能标签）
- `locatorBarHeads`：直接替换原版圆点的贴图，头像沿用圆点坐标与“按距离缩放”的尺寸，过滤命中或“只显示附近”时整条航点隐藏
  - `locatorBarHeadScale`：头像倍率 1～9 档（0.5x～1.5x，默认 5 = 原版圆点大小）
  - `locatorBarHeadHatLayer`：叠加皮肤第二层（帽子/头盔）
  - `locatorBarHeadBorder` / `locatorBarHeadBorderThickness` / `locatorBarHeadBorderColor`：描边样式（关 / 固定色 / 跟随队伍）、粗细与颜色
  - `locatorBarHeadNames`：名字时机（从不 / 总是 / 注视时 ±20° / 玩家列表打开时），150ms 滑入淡入，颜色跟随描边样式
  - `locatorBarHeadFilter` + `locatorBarHeadFilterNames`：玩家过滤（全部 / 仅名单 / 排除名单），名单支持逗号、分号、冒号、句点分隔
  - `locatorBarHeadNearbyOnly`：只给已加载（附近）的玩家画头像
- `locatorBarCompass`：S / W / N / E（可切换 `+Z/-X/-Z/+X`），60° 可视范围、91 像素半宽、边缘淡出、四向描边；通过 Fabric `HudElementRegistry.addLast` 注册，画在所有 HUD 元素之上；开启时经验等级数字上移 6 像素避让
- `locatorBarCompassColor` / `locatorBarCompassShadow` / `locatorBarCompassCoordinates`：字母颜色、描边与坐标标记
- `locatorBarAlwaysShowXp`：经验条与定位栏同时显示（强制经验条优先并把头像叠在经验条上；乘车时不强制）

### 物品分组（功能标签）
- 按 `BizCub/inventory-item-groups` 重写：默认组表、包含/排除/等价语义、先到先得去重、展开/收起、图标 1.5s 轮播
- 槽位贴图与上游逐字节一致（`icon_slot` / `item_slot` / `plus` / `minus`），tooltip 仅显示组名
- `itemGroupsShowItems` / `itemGroupsAddAll` / `customItemGroups` 子设置；自定义组列表不参与物品 ID 清洗
- 渲染与点击判定改为槽位快照 O(1)，搜索过滤、切换标签页、物品列表刷新时缓存正确失效

### 修复与修改
- `frostWalkerJumpFix`（修复）：跳跃过水面时按落点判定结冰，不再出现踩空
- `signOpenContainer`（修改）：穿牌打开背后容器，潜行右键仍优先编辑告示牌
- `disableCobwebSlowdown`（+`cobwebSlowdownAllEntities`）：禁用蛛网减速
- `disableFluidPush`（+`disableWaterPush` / `disableLavaPush`）：禁用液体水平推力
- `disableSlimeBlockSlowdown`（+`disableSlimeBlockBounce`）：禁用粘液块减速与弹跳
- `disableHoneyBlockSlowdown`（+`disableHoneyBlockStick`）：禁用蜂蜜块减速与黏着
- 铁傀儡只坐普通矿车：漏斗、运输、动力、TNT 等特种矿车不再被塞入

### 调试工具（测试标签）
- `debugInfoOverlay`（+`debugInfoShowPerformance` / `debugInfoShowTarget` / `debugInfoShowHooks`）：左下角调试叠加层，绘制前让出经验条与名字行
- `debugProbeReport`：快捷键把已激活的 Mixin 行为探针输出到聊天栏

### 配置与语言
- 新增 34 个配置项（`ConfigCatalog` 175 → 209 条），全部登记到对应标签页并配好 Sanitizer
- 四语言键集一致（各 977 键）；列表项统一使用 `config.lists` 前缀，修正自定义组与过滤名单显示原始键名的问题

- 新增 `LocatorBarHeadsTest`（9 例）与 `SignContainerTargetsTest`（7 例）；`CreativeItemGroupsTest` 扩到 15 例；`IronGolemMinecartStateTest`、`LangFilesTest`、`TweakifyModConfigScreenTest` 同步扩充
- `gradlew build` 全量测试通过
