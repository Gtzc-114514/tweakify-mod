## Tweakify Mod 1.1.8

本版本为功能与性能版本：新增存档游玩时长、不死图腾背包生效与更好的药水显示，并将配置写盘和几何重建移出主线程。

### 新增功能

- **存档游玩时长**：存档列表右上角显示累计游玩时长；合并 `players/stats` 与旧 `stats` 目录（同名玩家优先新目录），避免重复计数；支持小数小时 / 时钟 / 时长三种格式
- **不死图腾背包生效**：修改标签新增 `totemFromInventory`；主手/副手没有图腾时从快捷栏或主背包取图腾，效果与原版一致；手部已有图腾时保持原版优先，绕过无敌的伤害不触发；仅在单人/局域网生效
- **更好的药水显示**：原「药水效果时间显示」改名；新增 `statusEffectDurationScale` 滑条（50% ~ 200%，默认 100%），右上角效果图标与倒计时整体缩放；保留原版隐藏效果 HUD 的提前返回语义，低时长过滤与配色可调

### 性能

- **配置序列化异步化**：主线程仅构建不可变 JSON 快照，pretty printing 与写盘移入异步任务；保持提交顺序与退出时的同步兜底
- **几何双缓冲**：攻击范围与单层基岩几何改为共享后台 worker 构建，渲染只读取完整快照，旧任务不会覆盖新快照

### 文档与测试

- README 功能一览补充新功能，并为 8 个长 section 末尾补充「返回顶部」链接
- T6 配置序列化与几何双缓冲实机回归通过；存档时长新旧 stats 合并与三格式切换实机验证
- 747 个单元测试通过，1 个 Fabric Loader 集成测试与 6 个 GameTest 通过，`gradlew build` 通过

### 兼容性

- 1.1.7 → 1.1.8 无已有配置字段、存档或收藏数据变更；新增字段均有默认值（功能默认关闭，缩放默认 100%）
- 涉及服务端判定的新功能仅在单人/局域网生效
