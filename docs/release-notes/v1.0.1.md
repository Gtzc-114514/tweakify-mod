## Tweakify Mod 1.0.1

本轮为内部重构与工程改进，**配置项、JSON 键名与快照回滚行为完全不变**，可直接沿用 1.0.0 的配置文件；唯一的对外差异是 fabric-api 依赖下限收紧（见「兼容性」）。

### 架构
- 配置类按界面标签页拆分为 general / functions / modified / fix / optimization 五个分区，TweakifyModConfig 由 2077 行降至约 1250 行；扁平字段表与 JSON 格式保持一致

### 兼容性
- 11 处 @Redirect 迁移为 @WrapOperation，与其他修改同一调用点的模组可链式共存
- 8 个 Mixin 的 16 个 require=0 注入点补行为探针，注入失效时可在日志中定位
- 依赖要求：fabric-api 由任意版本收紧为 >=0.163.0+26.3

### 修复
- 加固 CI 上偶发的测试失败（时钟敏感断言改为锁存器 / 线程监视器快照 / 有界等待）

### 构建与发布
- 修复 Gradle 10 弃用语法、固定源码 UTF-8、开启构建缓存
- CI 合并 test 与 build、接入 setup-gradle 缓存；测试报告产物同时包含 HTML 与 JUnit XML
