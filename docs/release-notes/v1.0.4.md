## Tweakify Mod 1.0.4

本轮为**世界叠加层渲染性能优化**：屏障/基岩扫描半径翻倍并改为固定频率刷新，攻击范围刷新提速，基岩高亮与攻击范围改用顶点缓存；没有新增或改变任何配置语义，配置文件可直接沿用。

### 性能
- 屏障可见 / 单层基岩：扫描半径 16 → 32 格，体积从 33³ 增至 65³；分帧从每 tick 3 层提高到 22 层（约 3 tick 一轮），刷新与原版光照解耦为每秒 6 次
- 刷新调度：新增 `RefreshScheduler` 累计调度器，把“每秒 N 次”换算成每 tick 额度，20 tick 内精确触发 N 次，间隔在相邻整数 tick 间交替、长期不漂移
- 生物攻击范围：刷新由每 2 tick 改为每秒 12 次，开启功能时立即收集一次；未到窗口时沿用上一轮结果
- 顶点缓存：新增 `CachedGeometry`，基岩高亮与攻击范围在扫描结果/条目列表变化时重建一次顶点，渲染帧只做平移写入；攻击范围每帧不再重复计算三角函数与线段法线开方，基岩高亮不再逐帧计算六个面的坐标
- 空几何提交：提交前判断基岩面可见性与攻击范围视锥可见性，全部不可见时不再提交 0 顶点的 `debugFilledBox`（Vulkan 后端对提交次数敏感）
- 远坐标精度：基岩高亮的相机偏移放回 double 域相减，避免 |x| ≥ 10⁶ 时顶点量化导致高亮与方块错位

### 测试
- 新增 `RefreshSchedulerTest`：每秒 6 次的次数与间隔分布、200 tick 无漂移、重置、非法频率
- 新增 `CachedGeometryTest`：属性写入、扩容后旧顶点保留、重复 begin 重置计数、未启用属性读 0
- 新增 `BedrockGeometryCacheTest`、`AttackRangeGeometryCacheTest`：缓存失效条件、段/顶点数、坐标基准
- 新增 `AttackRangeStateTest`、`AttackRangeRendererTest`、`BedrockHighlightRendererTest`：刷新频率需求与提交前可见性边界
- `BlockMarkerScannerTest`：移除已失效的静止降频用例，保留 section 预筛覆盖并断言每秒 6 次

### 兼容性
- 对外功能与配置语义不变，`config/tweakify-mod.json` 沿用 1.0.3
- 本次未改动 Mixin 注入点，探针覆盖仍为 51/51
- 屏障/基岩的可见半径与刷新频率变化会改变视觉节奏：扫描半径翻倍、刷新更频繁，可在配置界面按需关闭
