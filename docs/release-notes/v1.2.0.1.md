## Tweakify Mod 1.2.0.1

本版本为 1.2.0 的补丁版本，修复聊天栏截图卡片完全不显示与横向错位的问题；无配置字段或存档变更。

### 修复

- **截图卡片不渲染**：卡片 Mixin 同时混入 `DrawingFocusedGraphicsAccess` 与 `DrawingBackgroundGraphicsAccess` 两个目标并携带可重映射的 `@Shadow`，被 Mixin 的多目标校验拒绝（`Found a remappable @Shadow annotation on graphics`），整个 Mixin 未被应用，聊天栏始终看不到缩略图。现拆分为聚焦与背景两个单目标 Mixin，两个通道各自生效。
- **卡片横向错位**：卡片原先按固定 `x = 0` 绘制，一旦 marker 前存在字符（续行缩进等）就会与文字错开。改为逐字符测量 marker 的实际起止位置，卡片精确覆盖其占位区域。
- **卡片行丢失**：卡片占位行曾设计为纯空格行，会被 `StringSplitter` 当作行尾空白裁掉，卡片没有渲染位置；现在卡片行同时携带时间与坐标，不会再被裁。

### 变更

- 聊天卡片改为两行布局：第一行是可点击的「标签 + 文件名 + 删除」，第二行左侧为 16×9 缩略图、右侧为截图时间与坐标。

### 兼容性

- 1.2.0 → 1.2.0.1 无配置字段、存档或收藏数据变更；改动仅影响聊天栏卡片的显示方式。
